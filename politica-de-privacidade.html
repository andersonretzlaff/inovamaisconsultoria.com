Política de Privacidade

Última atualização: 13 de novembro de 2026

Esta política explica como a Inova+ Consultoria trata os dados acessados pelo Campo Alegre Marketing, a ferramenta interna que usamos para gerenciar as contas Google dos nossos clientes. Ela vale para o aplicativo e para este site.

1. Quem usa a ferramenta

O Campo Alegre Marketing é usado apenas pela equipe da Inova+ Consultoria. Não há cadastro público. A ferramenta só acessa as contas Google cujo titular entrou com a própria conta e autorizou o acesso na tela de consentimento do Google.

2. Dados que acessamos pelas APIs do Google

Conforme as permissões concedidas na tela do Google, a ferramenta pode acessar:

  • Google Ads: contas, campanhas, grupos de anúncios, anúncios, palavras-chave, termos de pesquisa, orçamentos, conversões e métricas de desempenho.
  • Google Analytics: propriedades, fluxos de dados, eventos, conversões, vínculos com o Google Ads e relatórios agregados de acesso.
  • Google Tag Manager: contas, contêineres, espaços de trabalho, tags, acionadores, variáveis e versões.
  • Google Search Console: sites, desempenho na pesquisa (consultas, cliques, impressões), inspeção de URLs e sitemaps.
  • YouTube e YouTube Analytics: dados do canal, vídeos, playlists, comentários e relatórios do canal, incluindo relatórios de receita quando autorizados.

Não acessamos e-mails, arquivos do Google Drive, contatos, senhas nem dados de pagamento.

3. Para que usamos os dados

Os dados são usados somente para gerenciar as contas que o cliente autorizou: gerar relatórios, analisar resultados, propor melhorias e aplicar alterações aprovadas por uma pessoa. Não usamos os dados para nenhuma outra finalidade, como publicidade, revenda ou criação de perfis.

4. Compartilhamento

  • Não vendemos dados a ninguém.
  • Não compartilhamos dados para publicidade nem para qualquer finalidade que não seja a gestão das contas autorizadas.
  • Para analisar os dados, a equipe usa um assistente de inteligência artificial (Claude, da Anthropic), que processa as informações apenas para responder às solicitações da própria equipe. Os dados não são usados para treinar modelos de inteligência artificial.
  • Os resultados das análises são compartilhados apenas com o próprio cliente titular da conta.
  • Poderemos fornecer informações se a lei ou uma ordem judicial exigir.

5. Uso Limitado (Google API Services)

O uso e a transferência, para qualquer outro aplicativo, de informações recebidas das APIs do Google seguem a Política de Dados do Usuário dos Serviços de API do Google, incluindo os requisitos de Uso Limitado.

6. Armazenamento e segurança

A ferramenta roda no computador da Inova+ Consultoria. Não mantemos banco de dados em servidores na internet. Guardamos localmente apenas:

  • os tokens de acesso gerados pelo login do Google, que permitem à ferramenta acessar as contas autorizadas;
  • um registro (log) das chamadas feitas pela ferramenta, para conferência das alterações;
  • cópias de segurança de títulos, descrições e outras informações de vídeos do YouTube, feitas antes de cada alteração, para permitir desfazê-la.

Esses arquivos ficam em pasta protegida, acessível apenas à equipe. Os dados de relatórios são consultados nas APIs do Google no momento do uso e não são armazenados em banco próprio.

Mantemos os registros e as cópias enquanto prestamos o serviço ao cliente e os apagamos em até 30 dias após o fim da prestação de serviço ou após o pedido do titular.

7. Como revogar o acesso e pedir exclusão

O titular pode revogar o acesso da ferramenta a qualquer momento em myaccount.google.com/permissions, removendo o app “Campo Alegre Marketing”. A partir daí, a ferramenta não consegue mais acessar a conta.

Para pedir a exclusão dos tokens, registros e cópias relacionados à sua conta, escreva para o e-mail de contato abaixo. Atendemos o pedido em até 30 dias.

8. Seus direitos (LGPD)

Nos termos da Lei Geral de Proteção de Dados (Lei nº 13.709/2018), você pode pedir confirmação do tratamento, acesso, correção, exclusão e informações sobre o compartilhamento dos seus dados, pelo e-mail de contato.

9. Este site

Este site não usa cookies, não tem formulários e não usa ferramentas de análise de visitas. Ele é hospedado no GitHub Pages, que pode registrar dados técnicos de acesso (como o endereço IP) para segurança e funcionamento do serviço.

10. Alterações desta política

Se esta política mudar, publicaremos a nova versão nesta página, com a data de atualização.
